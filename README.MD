# Nexus Retail: Advanced SQL Analytics & Database Logic

This repository contains my practice and implementation of advanced SQL concepts using a custom-built e-commerce database (Nexus Retail). 

Key Concepts Covered
Window Functions: Applied `RANK()`, `DENSE_RANK()`, and `ROW_NUMBER()` for sales performance analysis.
Analytical Clauses: Used `OVER()` and `PARTITION BY` to calculate running totals and category-specific metrics.
Time-Series Analysis: Implemented `LAG()` and `DATEDIFF()` to track customer purchase frequency.
*Database Objects:
    Stored Procedures:** Built logic for "Atomic Order Cancellation" and "Automated VIP Promotion."
    Stored Functions:** Created custom calculators for stock status and tax applications.
    Views: Designed virtual tables for simplified business reporting.

Tools Used
Database: MySQL
Interface: MySQL Workbench
Language: SQL (DDL, DML)

Project Structure
- `Nexus_Retail_Advanced_SQL.sql`: The complete script including schema creation, data seeding, and advanced queries.
